About This App

這個應用使用 Google 的 Gemini API 來分析網頁內容並生成真實的多講者對話與 TTS。

Features:

  • 🔐 用戶認證: 使用 Supabase 的安全登入系統
  • 🌐 URL 分析: 自動抓取並分析網頁內容
  • 🤖 AI 對話生成: 使用 Gemini 2.5 Flash 創建引人入勝的對話
  • 🌍 多語言支援: 支援 16 種不同語言的對話生成
  • 🎭 多講者支援: 配置最多 2 個不同講者與獨特聲音
  • 🎨 聲音選擇: 從多個預建聲音選項中選擇
  • 💾 音頻導出: 下載生成的對話為 WAV 文件
  • 🎵 即時播放: 直接在應用中聆聽生成的音頻

Available Voices:

  • Kore: 自然、平衡的聲音
  • Puck: 充滿活力、俏皮的聲音
  • Charon: 深沉、權威的聲音
  • Fenrir: 強大、命令式的聲音
  • Aoede: 旋律優美、富有表現力的聲音

Supported Languages:

English, Chinese (Simplified/Traditional), Korean, Japanese, Spanish, French, German, Italian, Portuguese, Russian, Arabic, Thai, Vietnamese, Indonesian, Hindi

API Key:

從 Google AI Studio 獲取你的 Gemini API key
